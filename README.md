# 小伴助手

手机优先的纯前端学习与生活助手，Vue 3 + TypeScript + Vite + Vant + Pinia，可直接部署到 GitHub Pages，不需要后端或登录服务，提供两个带邀请码入口的本机档案。

## 启动和构建

```sh
pnpm install
pnpm run dev
pnpm run build
```

开发服务默认只监听 `127.0.0.1:8090`；需要局域网调试时显式运行 `pnpm run dev --host 0.0.0.0`。构建输出到 `docs/`。沿用当前 GitHub Pages 从仓库 `docs/` 发布的方式，由你自行提交和发布；构建会清空输出目录，手写文档不要放进去。

已发布站点： https://myd-website.github.io/audio/

使用 Hash 路由，例如 `/#/today`、`/#/study`、`/#/music`、`/#/planner`、`/#/fun`。仓库子路径下刷新页面不需要服务端重写，旧模块地址在应用内保留重定向。

这是供熟人使用的工具，入口 HTML 已添加禁止收录和 `no-referrer` 声明；重新构建、发布后生效。构建会检查公开目录及最终产物，阻止常见环境文件、私钥/令牌、源码映射和个人备份被误发布；可独立运行 `pnpm run audit:publication`。GitHub Pages 仍公开可访问；根域 robots 配置和完整检查结果见 [私用站点说明](deployment/PRIVATE_SITE.md)。

## 五个模块

| 入口 | 功能                                                                                     |
| ---- | ---------------------------------------------------------------------------------------- |
| 今天 | 当日任务和练习概览、完成进度、学习/音乐/日程快捷入口                                     |
| 学习 | 国家平台同步课程、小学语数英练习、错题复习、字词查询、计算器、竖式与分步讲解             |
| 音乐 | 指定在线音源入口、独立搜索适配、收藏、全局队列播放器、歌词、本机音乐库、裁剪转码         |
| 日程 | 周/月历、日期任务、分类/优先级/备注、完成记录、查找、未安排和逾期筛选                    |
| 娱乐 | 自定义转盘与模板、骰子/硬币/随机数、数字华容道、2048、猜数字、井字棋、记忆翻牌、专注计时 |

首次进入选择“档案一”或“档案二”，输入配置的邀请码后进入；空输入和错误邀请码均会提示，未验证时访问其他页面会回到 `/#/profiles`。两个档案分别验证，同一标签页刷新后保留验证，退出后需重新输入；旧版档案选择不会自动视为已验证。头像进入当前档案的偏好与数据，可切换档案；顶栏和设置均可退出当前档案，退出不删除记录。可保存昵称和默认年级、导出/恢复备份及导入旧待办。学习内容是首批基础专项，语文/英语按相邻两个年级组织难度，不代表完整覆盖某个版本的教材。

邀请码统一在 [src/config/invitation.json](src/config/invitation.json) 的 `code` 字段维护，两份档案共用，初始值为 `admin`。填写非空字符串、不要添加首尾空格，验证区分大小写；测试会读取同一配置，无需同步修改测试中的邀请码。开发时修改后整页刷新，已部署站点需重新构建发布。已有验证会话继续有效，需要体验新邀请码时先退出当前档案再进入。

## 学习练习与接口回退

### 国家平台同步课程

学习页的“跟着课本看同步课程”进入 `/#/study/courses`，支持语文、数学、英语，1～6 年级、上下册、教材版本、新旧教材、单元和课程名称筛选。语文沿用官方“统编版”名称；英语保留一年级起点、PEP、精通等实际版本，不混用内容。默认优先 PEP 和新教材；某个版本没有可展示课程时会明确提示，可切换版本或打开官方平台。

课程目录来自国家中小学智慧教育平台网站当前公开使用的 `national_lesson` 目录 JSON，不是已经取得授权的开发者开放 API，也不承诺这些地址长期稳定。2026-11-05 核验时目录文件允许无登录读取，但没有向本站开放跨域响应；官方网页也限制第三方嵌入。因此采用构建前同步目录、本网站按需加载本地章节分片、跳转官方页面学习的方式，GitHub Pages 无需后端或私密密钥。视频、教材正文、课件、习题答案和登录凭证均不下载、不转载；官方学习与播放可能需要用户自行登录。课程目录不是官方题库，原有基础练习没有被替换成教材同步题。

已同步目录随代码保存在 `public/courses/smartedu/v1/`，页面显示目录更新时间。日常启动、构建不请求官方目录；需要更新时手动执行：

```sh
pnpm run sync:courses
```

同步仅接受固定官方 HTTPS 目录地址，逐册读取元数据；所有册次成功并通过校验后才切换索引。分片文件名含内容哈希，失败不会覆盖已有索引或旧分片。旧的未引用分片不自动删除。接口变动时同步会明确失败，网站继续使用之前成功生成的目录；不要通过添加账号 Cookie 或访问令牌绕过资源权限。目录条目与新旧教材标注以官方当前数据为准，不能据此保证每册每课均已有资源。

可将具体课程加入当前档案的今日日程，保留教材与官方链接，同一天同一课程不会重复添加；完成状态由用户手动勾选。打开官方课程不会自动记为已学习，也不读取官方账号的学习记录。

验证课程目录、筛选、跳转、安全边界、同步失败保护及请求切换：`node --test tests/courses.test.mjs`。

课程筛选统一使用 `AppSelect` 选择面板，教材版本和课程数量分行显示，长单元列表支持搜索。查看课程可直接阅读课后笔记、重点易错、自测与演示卡片；目前接入学阶图谱 193 个小学语数英知识点，按教材册次和单元提供参考，不是每节课的官方配套讲义。其教学研究内容由上游 AI 撰写、未经实证验证，页面保留说明；《观潮》《繁星》另有明确标为本站整理的复习提纲，“圈画关键词与批注”有开源课件的九步阅读版，部分古诗可直接读原文（11 首资料，保留来源字形与异文）。默认读取本地快照，主动在线读取成功后相应笔记标为在线，失败保留本地内容。现代课文全文、教材原版 PPT 和官方视频尚未取得可确认的接入来源，仍保留官网入口。资料许可、固定版本、免费 JSON 地址和复现说明见 [站内课程笔记说明](deployment/LEARNING_NOTES.md)；其他免费资源见 [资源核验说明](deployment/FREE_LEARNING_RESOURCES.md)。

### 基础练习

- 数学每轮优先从接口盒子获取 1 道小学综合应用题，再以现有年级出题逻辑补齐最多 10 题。接口每次仅返回一道题、没有年级筛选，页面明确标记“不分年级”，不冒充所选年级教材题。语文、英语暂沿用本地基础题库。
- 使用来源文档公开的共享 ID / KEY，无需配置个人密钥。来源文档：`https://www.apihz.cn/api/zicishuxuex.html`。2026-11-04 实测公开接口返回 HTTP 200、题目/答案/解析，并允许跨域；共享额度和第三方服务可用性由来源网站决定。
- 在线查询最多等待 5 秒；网络、跨域、HTTP、业务、格式、字段缺失或内容超出记录上限时，自动使用本地题并显示原因。每个页面的在线请求至少间隔 6.5 秒，避免连续开局耗尽免费频次。切换学科、年级、模式或离开页面会取消请求，迟到题目不进入新练习。
- 在线应用题的答案可能是整句话，先输入答案、查看参考解析，再选择“我答对了”或“需要复习”才保存记录，避免按文字或数字强行判错；本地题继续自动判题。错题复习从已保存题目恢复，不联网，保留在线题的自行核对方式；原有记录和备份格式兼容。
- 本地数学每轮混合口算、未知数、生活应用及单位/周长/面积/百分数等年级基础题型。语文、英语每轮各 10 题：5 道原基础专项 + 5 道词义/拼音或双向词汇题。语文新增内容复用自编小学词语补充，属于通用积累，英语新增 36 个词按原三个难度带组织，不表示严格覆盖教材进度。题目逐题标注本地或在线；错题复习显示本地记录与原在线来源。
- 学习页与课程页均隐藏“免费资源与接口”介绍区域，资源核验记录保留在 `deployment/FREE_LEARNING_RESOURCES.md`。

## 娱乐玩法

娱乐页提供 8 种模式，支持通过 `/#/fun?tool=wheel|dice|puzzle|2048|guess|tic-tac-toe|memory|focus` 直接进入对应模式。

- 数字华容道为可解的 3×3 棋盘，点击空格旁的数字移动，也可聚焦棋盘后用方向键移动空格；记录步数和用时，切换模式暂停计时。
- 2048 支持滑动棋盘、聚焦棋盘后使用方向键 / WASD，或点击方向按钮；每轮同一方块只合并一次，无效移动不生成数字，达到 2048 后可继续挑战。
- 猜数字可选 1～100 或 1～1000，按提示缩小范围；井字棋支持人机和本机双人对战。
- 随机工具支持 1～3 颗立体骰子、翻转硬币和指定范围的随机整数；转盘、翻牌与游戏胜利均有动画反馈，并适配系统的“减少动态效果”设置。

小游戏的进度、得分和对战记录仅保留在当前娱乐页面中：切换模式保留，刷新或离开娱乐路由后重置，不进入备份。转盘模板继续随本机档案保存；专注倒计时离开娱乐页面仍会继续，关闭网站后不会提醒。

## 数据保存

- 提供“档案一”和“档案二”，首次进入需验证邀请码。两份档案的待办、学习记录、收藏、模板和偏好分别保存在 `aide:workspace:profile:one:v1` / `aide:workspace:profile:two:v1`，音乐分别保存在 IndexedDB `aide:music:profile:one` / `aide:music:profile:two`。
- 当前档案与邀请码验证状态通过当前标签页的 sessionStorage 一次保存，刷新后继续；退出时一起清除，关闭标签页后可能需要重新验证。切换档案会停止播放与计时，进入时完整刷新以清理运行状态，其他标签页继续使用各自的档案。
- 邀请码仅为纯前端使用门槛，代码公开可见，不提供服务端身份认证或可靠的隐私访问控制；不保存用户输入的邀请码。
- 无账号认证和跨设备自动同步。清除网站数据或切换浏览器会影响这些记录，建议定期导出 JSON 备份。
- 导出的 JSON 标注来源档案，恢复时明确显示来源和目标，只替换当前档案；兼容之前的无档案备份。JSON 备份不包含音乐文件；本机音频需要自行保留原文件。恢复备份会在确认后替换当前记录，不自动合并多设备修改。
- 保存失败保留输入与原记录；损坏数据提供原始数据导出，普通操作不会用空列表覆盖它。
- 改造前的 `aide:workspace:v1` 和 IndexedDB `aide:music` 保留。在设置中手动导入到选定档案，共享记录仅允许导入空档案，音乐自动去重、整批保存，不会自动复制给两个档案。旧共享记录也可以直接导出，再通过备份恢复。
- 旧版 `audio:todos:v1` 数据不会自动删除。在“偏好与数据”点击导入，重复导入自动去重；没有日期或完成时间的旧任务保留为未知。
- 旧待办在 `/#/planner/legacy`，旧版兼容工具仍使用原来的共享存储，不属于两个新档案。新日程与旧待办分别存储。

## 在线音乐的静态站点限制

音源使用 https://www.qqmp3.vip/ 。默认“原站搜索”：提交后加载音源页并显示关键词、复制按钮，请在音源页内粘贴关键词后搜索，也可新窗口打开。没有已核实的跨站自动填词协议，因此不声称已经替用户提交站内搜索。搜索、试听、歌词和下载由音源站点提供。嵌入页在切换页签或离开时停止，不与本机播放器和收藏互通；来源网站内的记录由对方管理，不随我们的本机档案隔离。

“接口搜索”在开发时通过 Vite `/music-api` 代理，生产时直接访问来源接口。2026-11-04 检查到详情接口返回 HTTP 200 和播放地址/歌词，但该响应没有 `Access-Control-Allow-Origin`；使用“天使的翅膀”实测本机代理和来源搜索接口均返回 HTTP 403 和“非法访问”，原站公开脚本中的备用域名本次连接超时。接口请求失败时，页面自动切换原站入口，保留本次关键词并显示失败原因；下一次搜索沿用原站方式，避免反复调用失败接口。仍需在音源页粘贴关键词并提交，原站本身能否搜索取决于对方服务。切换页签会取消请求，迟到结果不会覆盖当前页面；不使用公共中转服务绕过限制。

站点下载选项可能为网盘分享链接，页面标为打开来源，不假报下载成功。来源网站限制、资源有效期和嵌入能力不受本项目控制。本机音乐可使用我们的全局播放器，离开音乐页继续播放；在线歌曲仅在接口可读时进入该播放链路。

## 音乐导入、裁剪与 MP3 转换

1. 音乐页选择“本机音乐”，选文件后试听并确认导入；文件只保存在浏览器，不上传。
2. 进入“音频工具”，也可从本机歌曲的编辑按钮进入。
3. 输入或拖动起止点，使用当前位置/15 秒/30 秒快捷设置，试听选区。
4. 选择 MP3 或 WAV、MP3 128/192/320 kbps、是否淡入淡出。
5. 生成后试听并下载，由浏览器决定保存位置；系统铃声需要在设备中另行设置。

输入单文件最多 40MB、总时长最多 10 分钟，本机库最多 50 首；为控制手机内存，每次最多导出 5 分钟。输入格式取决于浏览器解码能力，不承诺所有格式均可处理。MP3 通过独立线程真实编码，WAV 为 44.1kHz/16 位 PCM；提高导出码率不等于恢复原音源音质。

编码使用独立加载、未修改的 LAME JavaScript 编码器 `lamejs 1.2.1`，项目地址 https://github.com/zhuker/lamejs ，LAME 主页 https://lame.sourceforge.io/ ，附带说明在 `public/licenses/lamejs-LICENSE.txt`。旧的多线程 FFmpeg 资源保留，当前工作台不依赖它。

## 竖式计算器

首页、学习页和设置均提供明显入口，不再只在数学学科下显示。日常计算器在 `/#/calculator`，支持手机数字键盘、括号、运算优先级、负数、小数及按顺序展示过程；中间值使用有理数，不使用 `eval`。竖式在 `/#/calculator?mode=vertical`，旧 `/#/maths` 自动跳转。支持加减乘除、对齐竖式与分步说明。每个数最多 12 位整数、6 位小数；除法最多展示 10 位小数，使用 `≈` 或 `…` 标记近似/截取结果。算式最长 160 个字符、嵌套最多 24 层；手机端保留竖式区域独立横向滚动。

加法在对应数位上方显示带“进位”标签的橙色小数字，支持连续进位和小数跨位；乘法在各行积上方分别标出该行相乘的进位值，随部分积左移。没有进位时不显示标记，减法保留独立的借位提示。

日常计算器可切换“标准 / 科学”键盘。科学模式支持乘方 `^`（右结合，先于一元负号）、平方根 `sqrt` / `√`、三角及反三角函数、自然对数 `ln`、常用对数 `log`、自然指数 `exp`、绝对值 `abs`、常数 `π` / `pi` 与 `e`、阶乘 `!`、百分数 `%` 和科学记数法（如 `1E-3`）。默认 DEG 角度制，可切换 RAD 弧度制；切换单位后需重新计算。函数参数必须加括号，乘法必须显式写出，如 `2×sin(30)`；`10%` 表示 `10÷100`。阶乘仅支持 0～100 的精确整数，整数幂指数绝对值最多 1000，科学记数法输入指数为 −100～100；超出结果容量或实数定义域时明确报错。四则运算和可精确计算的整数幂、开方保留有理数精度，科学函数及常量参与时使用浮点近似并显示 `≈`；极小结果使用科学记数法，避免显示成零。按键支持在光标处插入及替换选区。

组件：`src/modules/study/components/PocketCalculator.vue`、`src/components/math/ArithmeticCalculator.vue`、`CalculationProcess.vue`；逻辑：`src/modules/study/domain/expression.ts`、`src/utils/arithmetic.ts`。

## 字词查询与接口回退

从首页或学习页打开汉语字典、汉语词典、成语大全、英汉词典，路由为 `/#/study/dictionary?kind=character|word|idiom|english`。

- 汉字默认优先查询接口，英语默认直接查询本地英汉词库。在线查询遇到 HTTP/网络/跨域错误、8 秒超时、业务或格式错误及在线未收录时，自动改查本地词库；在线成功不读取本地分片。页面显示来源和回退原因。
- 汉字接口为 `https://xiaoapi.cn/v1/hanzi.php?msg=学`，无需密钥。本次实测返回成功且允许跨域；多音字按读音分别展示释义、发音和组词。
- 汉字的部首、笔画、结构、笔顺 GIF、字形 PNG、近反义词、补充字义和百科入口按接口实际提供的字段展示；字形资料集中展示一次，多音字不重复堆叠。动图加载失败时尝试静态图，两者均失败可重试，不影响释义；图片等比显示，窄屏单列，长说明默认折叠。图片和百科地址统一使用 HTTPS，不安全地址忽略。
- 英汉词典默认展示中文释义、音标和词形变化，可展开词库自带的英文释义，不必等待在线接口。点击“在线英文释义与发音”才查询 Free Dictionary API，保留来源与许可链接，可随时返回英汉释义；下一次普通查询仍默认中文。在线模式仅提供英文解释；本地未收录时明确提示，可打开备用词典。本地分片加载失败会报错，不会拿英文解释冒充中文释义。真实在线发音仍未验收。
- 已查到的词语/成语综合接口要求密钥，不在公开前端暴露私密密钥；这两类当前使用本地词库，支持完整词条及开头匹配。
- `public/dictionaries/v1/` 保留约 55MB 回退数据，按首字码点分为 128 片，每次只加载相关分片，最多缓存 8 片；不会首次下载整库，也不承诺首次离线可用。不存在的词条明确提示，接口和本地同时加载失败则显示错误，不伪装成空结果。
- 本地汉语来自 `pwxcoo/chinese-xinhua`（版本 `fe6d6c2e8baa82187f4c96bbe042e43f96c05666`），含 16,142 条汉字、264,414 条词语、30,895 条成语。词语包含 24 条明确标为自编的小学补充内容；不是官方新华字典版本。
- 本地英汉来自 `skywind3000/ECDICT`（版本 `39cfb9672c0906b63569e0453c2e6abfb9ab182a`），提取 36,646 条核心、考试与高频词。许可见 `public/licenses/chinese-xinhua-LICENSE.txt`、`ECDICT-LICENSE.txt`。社区内容可能有缺项或错误，请结合教材核对。

日常启动和构建直接使用已有词库。需要重新生成时，从上述仓库固定版本取得 `data/word.json`、`data/ci.json`、`data/idiom.json` 和 `ecdict.csv`，脚本会校验四份源文件的 SHA-256；可选最后一个参数指定其他输出目录用于验证。

```sh
node scripts/prepare-dictionaries.mjs /path/to/word.json /path/to/ci.json /path/to/idiom.json /path/to/ecdict.csv
```

## 手机比例和退出

按当前要求固定页面缩放比例，使用 viewport、touch-action 和 Safari 手势处理，保留单指滚动与竖式横向滑动；系统强制的辅助缩放仍由浏览器/操作系统决定，尚未做手机真机验收。

软键盘适配统一应用于搜索、答题、设置和弹层编辑：键盘弹出后按实际可视区域自动滚动，短表单尽量同时露出输入框和提交按钮，长表单优先当前输入框；底部弹层移到键盘上方并在内部滚动。兼容可视视口缩小、窗口随键盘缩小及无 VisualViewport 的回退，键盘打开时隐藏底部导航和迷你播放器，收起后恢复。手动滚动不反复拉回输入框。回归验证：`node --test tests/mobile-viewport.test.mjs`；iOS / Android 真机键盘仍需验收。

退出先经过练习或编辑页原有的离开确认，再移除当前标签页 sessionStorage 中的档案选择并完整刷新。两份档案数据与本机音乐均保留；存储失败会提示，其他标签页不受影响。
