## 数学计算器

- 访问 `/maths`，选择加、减、乘、除，输入两个数后点击“分析计算过程”，也可直接点击示例。
- 展示对齐竖式和逐步说明：加法进位、减法连续借位、乘法部分积、除法试商与余数。
- 支持负数及小数，每个数最多 12 位整数、6 位小数；输入为空、格式错误或除数为 0 时会显示提示。
- 加减乘使用十进制定点整数计算。除法最多展示 10 位小数，仍有余数时使用 `≈` 和 `…`，表示截取展示而非四舍五入。
- 修改输入或切换运算方式会清除旧结果。长竖式可在区域内左右滑动。
- 手机宽度不超过 480px 时，上下排列输入框；输入框旁的 `±` 可切换正负号，适用于没有负号的小数键盘。键盘“下一项”切换到第二个数，“完成”执行计算，成功后收起键盘并滚动到结果。
- 计算器保持至少 44px 的触控区域和 18px 的输入字号；这两个数学组件单独保留像素尺寸，避免随全局 rem 缩放而缩小。长竖式只在自身区域滚动。

复用组件：`src/components/math/ArithmeticCalculator.vue`，可传入 `initial-operation="add|subtract|multiply|divide"`，不依赖路由；竖式展示组件为 `CalculationProcess.vue`，计算逻辑位于 `src/utils/arithmetic.ts`。

## 手机待办清单

- 访问 `/todoList`，输入内容后点“添加”或按回车；内容会去除首尾空白，最多 120 字。
- 点击任务左侧圆圈完成或恢复；通过“全部 / 待办 / 已完成”筛选，全部列表中未完成任务排在前面。
- 点击任务右侧“…”编辑或删除，删除前需要确认。编辑时切换筛选或编辑其他任务会提醒先保存或取消，避免丢失草稿。
- 任务自动保存在当前浏览器的本地存储，刷新、离开页面后仍保留；不跨设备同步，清理浏览器数据会丢失记录。旧版仅存在内存中的任务无法在刷新后找回，新版不再注入示例任务。
- 保存失败时保留输入并提示，读取失败时不覆盖原数据；多个标签页更新时同步列表，并在检测到旧数据冲突时要求重试操作。
- 手机输入字号至少 16px，主要点击区域至少 44px；长任务自动换行，底部保留安全区。地址管理和聊天室入口保留在页尾。
- 待办页宽度不超过 480px 时，勾选、更多操作和筛选等触控区域增至 48px；不超过 360px 时新增输入框与按钮上下排列。
- 编辑使用多行文本框，回车换行，点击“保存修改”保存。输入期间根据可视区域调整滚动，优先展示输入框和保存按钮；横屏空间不足时优先保证输入框可见。支持双指缩放，缩放时不主动调整滚动位置。

页面组件：`src/components/todo/TodoBoard.vue`；状态与存储逻辑：`src/components/todo/useTodoList.ts`。
